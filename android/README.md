# CallMe Android 0.24

这是一个验证模拟来电核心能力的原生 Android 实验工程，包含系统手机来电、微信风格
语音来电和微信风格视频来电三种实验模式。

## 当前范围

- 来电类型：手机来电、微信风格语音、微信风格视频
- 姓名和显示号码可以修改并自动保存（默认“老板”）
- 使用非紧急测试号码 `01055550123`
- 延迟可选：10 秒、30 秒、1 分钟、5 分钟、10 分钟、30 分钟、1 小时
- 支持立即触发和 `AlarmManager` 精确调度
- 支持输入 1 秒到 24 小时的自定义延迟
- 首页显示当前已安排任务，App 重启后仍可查看或取消
- 手机重启或重新授予精确闹钟权限后，会恢复仍未过期的等待任务；超过计划时间 2 分钟的残留状态会自动清理
- 触发日志记录计划时间与实际触发时间的毫秒偏差
- 手机来电由系统电话页面负责接听和拒绝
- 微信模式使用高优先级全屏通知、前台响铃服务和本地语音/视频页面
- 微信自绘页面按厂商选择小米、华为/荣耀、OPPO 系、vivo 系、三星或通用布局配置；小米配置已按真机截图校准
- 微信模式 60 秒无人接听会自动停止，返回退出会按拒绝/结束处理，旋转屏幕后保留接听状态和通话计时
- 微信语音/视频默认使用从本机官方微信 APK 只读提取的“微信经典”铃声
- 微信模式支持逐个试听内置铃声，也可从“文件”中选择自定义来电铃声
- 接听后的微信页面提供静音状态、扬声器路由、摄像头开关、前后镜头切换和挂断
- 三种模式都支持选择接听后播放的本地音频
- 两类音频均支持试听和停止，文件无法读取时记录明确错误
- 实验日志保存在本机，便于区分“闹钟没触发”和“Telecom 调用失败”
- 设置页显示设备、系统、关键权限和最近活动，并可一键复制不含媒体文件的完整诊断报告
- 可把当前联系人、来电方式、延迟、铃声和接听音频保存为本地模板；首页显示最近三个模板

明确不包含：服务器、推送、通讯录、录音、麦克风、好友分享、账号和数据库。

“微信风格”只是本 App 自己绘制的模拟页面，不会连接、登录或调用微信，也不会冒充真实微信服务。
“微信经典”铃声只用于用户本人的本地 Demo；在获得腾讯明确授权前不能随 App 对外发布。

## 架构

```text
主页面 → AlarmManager.setExactAndAllowWhileIdle → BroadcastReceiver
  ├─ 手机来电 → TelecomManager.addNewIncomingCall
  │               → ConnectionService / Connection
  │               → 系统电话 App 来电页面
  └─ 微信风格 → 前台响铃服务 + 高优先级全屏通知
                  → 本地语音/视频来电页
```

代码不会调用 `TelecomManager.placeCall()`，因此不会拨出真实电话。

## 首次真机设置

1. 安装并打开 App。
2. 允许“电话状态”权限。
3. 手机来电模式：点击“在系统中启用 CallMe”，在系统通话账户中打开它。
4. 微信模式：允许通知；Android 14 以上还要允许全屏来电。
5. 点击“允许精确闹钟”，允许该 App 按指定时间触发。
6. 选择需要的来电模式、延迟和音频。
7. 先点“立即测试当前来电”，确认基础链路正常。
8. 再安排延迟来电，立即锁屏并等待。

不同厂商的通话账户、后台和电池管理页面名称可能不同，因此最终结论必须基于真机实验。

## 实验顺序

| 场景 | 定时器触发 | 响铃 | 亮屏 | 系统来电 UI | 可接听/拒绝 |
|---|---|---|---|---|---|
| 立即触发，App 前台 | 待测试 | 待测试 | 待测试 | 待测试 | 待测试 |
| 10 秒，App 前台 | 待测试 | 待测试 | 待测试 | 待测试 | 待测试 |
| 10 秒，App 后台 | 待测试 | 待测试 | 待测试 | 待测试 | 待测试 |
| 点击后立即锁屏 | 待测试 | 待测试 | 待测试 | 待测试 | 待测试 |
| 锁屏一段时间后再安排 | 待测试 | 待测试 | 待测试 | 待测试 | 待测试 |

上述场景应分别对“手机来电”“微信语音”和“微信视频”测试一次，并记录手机品牌、型号、
Android 版本、默认电话 App，以及是否打开了厂商的自启动/后台运行设置。

若失败，先看 App 内“实验日志”：

- 没有“10 秒定时器已触发”：优先检查精确闹钟或厂商后台限制。
- 有定时器记录、没有 `addNewIncomingCall`：检查通话账户是否启用及权限。
- 已调用 `addNewIncomingCall` 但没有来电 UI：记录手机品牌、系统版本和默认电话 App。
- 微信模式只有通知、没有全屏：检查“全屏来电”权限和厂商锁屏显示权限。
- 微信模式不响：检查媒体/铃声音量、音频文件访问权限以及 App 内日志。
- 升级旧实验版后，App 会迁移到新的无声通知声道，避免通知声与所选来电铃声重复播放。

## 已知平台边界

- 系统手机来电的 UI 和来电铃声由手机的默认电话 App/系统控制，因此 App 只提供“打开系统铃声设置”。
- 自定义来电铃声由微信风格模式的前台响铃服务播放。
- 不同品牌会额外限制自启动、后台运行或锁屏显示。设置页会识别厂商、显示当前 UI 配置并提供对应设置入口，但仍须真机验证，无法仅靠编译保证所有型号表现一致。
- 目前只有小米 / Redmi / POCO 配置按真实小米截图校准；其他厂商配置是响应式适配基线，需要对应真机截图继续调整。
- Android 14 以后全屏通知权限受到系统限制，需要在真机设置中确认。
