# CallMe 安装与使用

这份说明面向拿到项目源码或私下测试包的其他使用者。CallMe 没有账号和服务器，所有配置、
头像、音频和日志只保存在安装它的设备上。

## iPhone：其他人如何使用

### 免费方式：每个人用自己的 Mac 和 Apple ID 签名

1. 在 Mac 安装 Xcode，并打开一次完成组件安装。
2. 用数据线首次连接 iPhone，在手机上选择“信任”。完成首次配对后，可在 Xcode 的
   **Devices and Simulators** 中勾选 **Connect via network**，以后在同一网络中无线运行。
3. 打开 `CallMe.xcodeproj`。
4. 在 Xcode **Settings > Accounts** 登录自己的 Apple ID。
5. 选择 **TARGETS > CallMe > Signing & Capabilities**，勾选自动签名并选择自己的
   Personal Team。
6. 把 Bundle Identifier 改成自己唯一的值，例如 `com.example.callme`。
7. 在 iPhone 开启 **设置 > 隐私与安全性 > 开发者模式**，按提示重启。
8. 在 Xcode 顶部选择该 iPhone，按 `⌘R` 安装。

免费 Personal Team 适合个人测试，签名到期后需要重新用 Xcode 安装。不能把一份免费签名的
IPA 长期发给所有朋友使用。

### 长期分发

项目所有者需要加入 Apple Developer Program，再根据测试范围选择 TestFlight、注册设备的
开发/Ad Hoc 分发或其他符合 Apple 规则的方式。当前项目没有配置这些正式分发链路。

### iPhone 首次测试

1. 先关闭静音和专注模式，并把铃声音量调到可听范围。
2. 打开 CallMe，先选择“手机来电”和 10 秒。
3. 点击安排后立即锁屏，观察是否响铃、亮屏并显示系统来电页。
4. 再分别测试微信语音和微信视频。前台是自绘页面；锁屏或后台会由 CallKit 接管。
5. 若失败，到“设置与诊断”复制报告。

## Android：其他人如何使用

### 从源码构建

需要 JDK 17 和 Android SDK：

```bash
cd android
./gradlew testDebugUnitTest assembleDebug
```

APK 位于 `android/app/build/outputs/apk/debug/app-debug.apk`。

### 私下安装 APK

1. 把可信的 APK 传到手机。
2. 按系统提示，允许当前文件管理器或浏览器“安装未知应用”。
3. 安装并打开 CallMe。
4. 完成 App 设置页列出的权限。

不要安装来源不明或签名不一致的 APK。当前仓库含有仅限个人本地验证的第三方铃声，不应把
包含它的 APK 公开上传到 GitHub Release 或应用商店。

### Android 首次权限

- 手机来电：电话状态权限、CallMe 通话账户、精确闹钟。
- 微信语音：通知、全屏来电、精确闹钟、后台弹窗/自启动。
- 微信视频：在微信语音权限基础上增加相机权限。
- 各品牌：按“设置与诊断 > 手机适配”提示关闭电池限制或允许后台启动。

系统电话页面由手机默认电话 App 决定，会随品牌和系统版本变化。微信语音/视频是 CallMe
自绘页面；设置页会显示当前识别到的小米、华为/荣耀、OPPO 系、vivo 系、三星或通用配置。

## 常见问题

### 到时间没有弹出来

先看诊断日志是否出现“定时器已触发”。没有触发通常是精确闹钟或厂商后台限制；已经触发
但没有页面，则检查全屏来电、后台弹窗或通话账户。

### 静音时为什么不响

系统电话和 CallKit 受设备静音、专注模式和系统铃声音量控制。App 不能只为自己强制覆盖
这些设置。Android 微信自绘模式还可能受到媒体/铃声音量和厂商音频策略影响。

### 为什么不同手机画面不完全一样

系统电话由默认电话 App 绘制，本来就会不同。微信自绘页面会选择厂商布局基线，但状态栏、
导航栏、刘海、屏幕比例和权限弹窗仍由系统控制。除已用截图校准的小米配置外，其他品牌需
要对应真机截图继续调整，不能仅靠厂商名称保证像素级一致。

### 能不能像普通 App 一样直接下载

Android 可以制作签名 APK 私下测试；iPhone 免费 Personal Team 不适合向多人长期分发。
此外，当前保留的微信铃声没有公开再分发授权，所以现阶段更适合私有仓库和个人设备测试。
